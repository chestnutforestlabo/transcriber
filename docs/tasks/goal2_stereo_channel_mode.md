# Goal 2: 2ch マイク録音(1話者=1チャンネル)モードの追加

## 背景とユースケース

- 2人の日本語会話を **DJI Mic Mini 2(2TX + 1RX)** で録音する。
- 受信機(RX)をステレオモードに設定すると、トランスミッター1(話者A)が Lch、トランスミッター2(話者B)が Rch に分離録音された 2ch WAV が得られる。48kHz/24bit。
- つまり「どのチャンネルか=誰が話したか」が既知なので、ダイアライゼーションモデルは本来不要。チャンネル情報を使えば話者識別は決定論的にできる。

## 現状の問題点(コードを読んで確認済み)

1. `src/backend/transcribe.py` の `_to_mono` がステレオを平均してモノラル化し、`data.py` の `__getitem__` もチャンネルを区別しないため、2ch 録音の話者情報が完全に捨てられ、モノラルミックスに対して pyannote を回している。
2. ピンマイクは無指向性なので、話者Aのマイク(Lch)にも話者Bの声が小さく漏れ込む(クロストーク)。単純に L/R を別々に ASR すると、漏れ込んだ相手の発言まで二重に文字起こしされる。

## 実装してほしいこと

### 1. チャンネル分離モードの追加

- `transcribe.py` に `--channel_mode` フラグ(または `--diarization_model_name channel` の choice 追加。CLI 設計はきれいな方でよい)を追加する。
- このモードでは:
  - 入力 WAV が 2ch であることを検証(1ch ならエラーメッセージを出して通常モードを案内)。
  - `data.py` にステレオを保持する読み込みパスを追加(既存の `_shrink_long_silences` / `_split_by_silence_candidates` は両chに同じ境界を適用し、L/R の時間同期を絶対に崩さないこと)。
  - 各チャンネルを独立に ASR(既存の `--asr_model_name` で選んだモデル)にかける。
  - 話者ラベルは `SPEAKER_00`(Lch)/ `SPEAKER_01`(Rch)として、既存の JSON フォーマット(start/end/speaker/text)で 1 本のタイムラインにマージして出力する(start でソート)。フロントエンドはそのまま動くはず。

### 2. クロストーク(漏れ込み)対策 — このモードの品質の要

- ASR 前に各チャンネルへ「本人発話ゲーティング」を行う:
  1. 各 ch で VAD を実行(推奨: silero-vad。軽量・依存が少ない・CPU で動く。pyannote の VAD でも可)。
  2. 検出された発話区間ごとに、同時刻の L/R の RMS(短時間フレーム平均)を比較する。
  3. 自ch RMS が相手ch RMS より明確に小さい区間(目安: -6dB 以下。定数としてまとめ、CLI で調整可能に)は「相手の声の漏れ込み」と判定し、その ch の ASR 対象から除外(該当サンプルを無音化 or 区間ごと skip)。
  4. 両者が同程度(=同時発話)の区間は両 ch とも残す(オーバーラップは両話者の発言として出力されてよい)。
- ヒステリシス/最小区間長(例: 0.2秒未満の判定反転は無視)を入れて、判定がフレーム単位でばたつかないようにする。
- 閾値定数は 1 箇所にまとめてコメントで根拠を書く。

### 3. README への録音手順の追記(日本語)

- DJI Mic Mini 2 での推奨録音設定を README に追記:
  - RX の録音モードを「ステレオ」(TX1→L, TX2→R)にする。モノミックスでは本モードは使えない。
  - トランスミッター側ノイズキャンセリングは弱め推奨(ASR には過度な NC が悪影響のことがある)。
  - 取り込み後は `audios/num_speakers_2/`(既存の命名規則)に WAV を置き、`--channel_mode` を付けて実行する。
  - 48kHz で録れた WAV は既存パイプラインが 16kHz にリサンプルするのでそのままでよい。

### 4. 3人・1マイク録音との共存

- `--channel_mode` なし(モノラル or 通常ステレオ)の既存フローは一切挙動を変えないこと。

## 制約・受け入れ基準

- **GPU は現在ドライバ不調で使えないため、GPU 実行での動作確認は不要**。
- pytest を `tests/` に追加:
  - 合成ステレオ WAV(例: Lch に 440Hz トーン区間、Rch に 880Hz トーン区間、互いに -12dB の漏れ込みを人工的にミックス)を numpy で生成し、ゲーティングが漏れ込み区間を正しく除外し、本人区間を残すことを検証する(ASR はモックする)。
  - L/R 時間同期がプリプロセス後も保たれることを検証する。
- silero-vad 等の依存を追加する場合は `pyproject.toml` を更新(`uv lock` が通らない環境なら README に記録)。
- 変更はすべて現在のブランチにコミットせず、ワーキングツリーに残すこと(レビュー後に人間がコミットする)。
- Goal 1 の変更(DiariZen 追加等)と同じワーキングツリー上で作業するため、`utils.py` / `transcribe.py` の変更は競合しないよう既存構造を尊重して統合すること。
